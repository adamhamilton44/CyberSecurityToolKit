# CSTK reporting component

This component is being integrated on a feature branch. Keep the installed main
checkout unchanged. Follow repository AGENTS.md for interface synchronization.
Never persist passphrases or notebook keys in argv, environment, source or logs.
Preserve guard scope, expiry, redirect, cancellation and source-IP checks.
Encrypted reporting is independent of optional diagnostic logs. Recording an
observation does not confirm a finding. Test encryption/review/retention changes.
Render Word/PDF samples when layout changes. Never delete retained notebooks on
update or uninstall. No AI generation, delivery, or automatic evidence deletion.
