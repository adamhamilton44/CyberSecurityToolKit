# Third party notices

The included license/notice files are copied from the installed dependency
metadata used for the prototype binary build. Their original licenses continue
to apply. BUILD_VERSIONS.json records the selected versions. Python itself is
licensed under the Python Software Foundation license; the source and binary
build also depend on the platform C runtime and OpenSSL supplied by dependencies.
LibreOffice is external and is not bundled in this package. UPX packaging does
not change the license of the packed program.

This directory is a prototype dependency record, not a complete redistribution
compliance audit. Preserve the upstream license texts and review distribution
requirements before a public release of this new reporting component.
